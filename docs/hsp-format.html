The .hsp page format

Every page in Hypnospace Outlaw is a 300-pixel-wide Construct 2 array. Here is what each of its 21 slots means, traced to the game's own code.

Derived from the shipped GOG build (HypnOS 2.5) by decompiling package.nw. Nothing here is guessed from observation: each field below is cited to the function that reads it.

The developers left a note in data/read this.txt saying they deliberately shipped everything unencrypted. They were not exaggerating — the game is a Construct 2 HTML5 export inside an NW.js wrapper, and data.js contains the full project model. Reading it turns this from archaeology into transcription.

01 Container

An .hsp file is a Construct 2 Array export: UTF-8 JSON, no BOM, one object.

{"c2array": true, "size": [W, 21, 21], "data": [ ... ]}

data is indexed data[x][y][z]:

AxisRangeMeaning
x0 … W-1Element index. x = 0 is always the page itself.
y0 … 20y = 0 is the element header; y >= 1 are states.
z0 … 20Property slot.
y axis
y = 0   headertype · id · name
y = 1   DEFAULT21 properties
y = 2   TRUETRANQUILITY21 properties
y = 3   ABBYDETAINED21 properties
… up to y = 20unused slots are ""

Every shipped page uses a 21×21 cross-section, so there is room for one header row plus twenty states. Unused cells hold the empty string.

Parsing trap

Values are stored as JSON strings almost everywhere, but a handful are JSON numbers. The runtime coerces everything through Construct 2's int(), which is parseInt — it takes the leading numeric prefix and discards the rest. Treat every cell as a string and parse it the same way, or a few real pages will decode wrongly.

The header row

zMeaning
0Element type: Webpage, Gif or Text. Those three and blank are all that exist.
1Element id. The runtime overwrites this slot with a live object UID.
2Element name — the label shown in the Page Builder's element list.

State selection

Row y = 1 is always DEFAULT. Later rows are conditional variants named after story flags — TRUETRANQUILITY, ABBYDETAINED, MINDCRASH, GOOPERREMOVED — or authoring scratch slots TEMP 01 through TEMP 17. Fifty-seven distinct names appear across the shipped pages.

The resolution rule, from ElementEventWeb: walk y = 1, 2, 3 … until the state name is empty, and take the last row whose trimmed, upper-cased name is a currently-true flag. DEFAULT is always true, so row 1 is the fallback. Each element resolves independently — one page can mix states.

02 Coordinates

A page is 300 pixels wide, always. Its height is max(int(z[3]), 1) × 32 pixels — the page-height field counts 32-pixel bands, not pixels.

The two element types anchor differently, which is easy to get backwards:

  • A Gif's x/y is the centre of the image.
  • A Text box's x/y is its top-left corner.

Text is also positioned in percentages rather than pixels. The box is first centred in the page, then nudged:

boxWidth = (z3 == 0) ? 300 : 300 * min(int(z3) * 0.01, 100)
boxX     = int((300 - boxWidth) / 2) + int(z1) * 3      // 3 == 300 * 0.01
boxY     = int(z2)

The off value is −1, not 0

The sway and dither speeds are gated on >= 0. Zero genuinely does collapse the element to nothing — it is just that no shipped page uses zero. Treating 0 as "disabled" makes every affected gif render at sub-pixel size, which is exactly the bug this spec was written to stop you hitting.

Z-order

UpdateZOrder walks the array from the last element down to the first, pushing each one behind the window frame in turn. The net effect is that a higher element index sits further back — array order is painting order reversed.

05 Text escapes

Implemented natively as HypnoSpecial_ReplaceText, applied in this order:

InputOutput
/nLine break.
//nA literal /n. Likewise //N.
/tTab — one glyph, seven space-widths wide.
//tA literal /t. Likewise //T.
/pThe player's name, prefixed with a zero-width § marker.
//pA literal /p. Likewise //P.
’A plain apostrophe.
#NAME#The value of script variable NAME.
#ConsoleA#Gamepad button glyphs, through #ConsoleY#.

The doubling trick is why the order matters: each //x form is swapped for a private-use character before the single form expands, then swapped back.

06 Image lookup

A gif's z[5] is a name, not a path. At startup the game scans four directories under data/images/ and matches case-insensitively against the first hit:

#DirectoryShape
1gifs/<name>/A directory of frames, used in listing order. A file called NN.speed sets the frame rate from its first two characters; the default is 5 fps.
2static/<name>.pngSingle image, 0 fps.
3shapes/<name>.pngSingle image, 0 fps.
4wordart/<name>/Directories of per-letter glyph images.

Files that do not end in .gif, .jpg, .jpeg, .bmp or .png are skipped. Page backgrounds are looked up separately, from images/bgs/, lower-cased, and they tile.

07 Links and scripts

An element's z[10], and the page's z[11], hold a |-separated list of command:parameter pairs. A bare path with no colon is a page link.

tooltipHover text.
sfxPlay a sound.
EventSet a story flag — this is what switches elements to a non-DEFAULT state.
virusInfect the page.
setloadspeedOverride the simulated load time.

password, wait, signal, buy, openfile, downloadfile, groupactive, hypii …Game-logic commands, dispatched by the same interpreter.

How a link looks

Every linked element gets a nine-patch box pinned to it — t160 for a Gif, t161 for a Text, both drawn from pagelinkgif-sheet0.png. For text it is created at X-2, Y-2 sized W+4, H+4, so it sits 2px outside the element.

The box is marching ants. Its Default animation is 4 frames at 8 fps, looping, with 9-patch margins of 4 on every side, so the edge tile is 4px: two pixels of dash, two of gap, stepping one pixel per frame — a full cycle twice a second. The step is clockwise: the top edge moves right, the left edge moves up. Each dash is one pixel of #9ac7f5 over a one-pixel rgba(33,33,73,.63) drop shadow, offset down and to the right. (The sheet also carries a 16-frame Old animation of 24×24 frames, which the object does not use.)

It is created with SetVisible(0) and stays hidden. The Links group reveals it only while the pointer is over it: the whole reveal sits under Mouse.IsOverObject, the matching Else hides every box, and a sweep hides any box whose UID is not the hovered linkUID. Exactly one box is ever on screen, and only while hovered — links are otherwise unmarked.

Paths are capture-relative

This is the subtlety that breaks naive converters. Links are authored against a logical root of hs\, but the directory actually served is the current capture — hs, hsa, hsb or hsc, one per chapter. URLtoCurrent rewrites the first path segment to whichever capture is live, unless that segment is ex or is itself a filename.

So the same link text resolves to a different file depending on which chapter you are in, and a link written hsb\zone\p.hsp read from an hs page loads hs\zone\p.hsp.

A path that names a directory resolves to home.hsp, falling back to zone.hsp.

A bug that isn't

A handful of shipped links carry the "no link" sentinel glued to the front: -1hs\02_the cafe\~thedumpsterhallo.hsp. They look broken and they are not. The segment rewrite replaces -1hs wholesale, so they resolve correctly — reproduce the rule and you inherit the repair for free.

08 Colours

Colours are packed decimal integers in BGR order. The low byte is red, not blue.

r =  c        & 255
g = (c >>  8) & 255
b = (c >> 16) & 255

Recolouring goes through Construct 2's replacecolor shader with a tolerance of 0.01 — an exact swap of one source colour, not a tint:

  • Text swaps pure black. The font sheets are black glyphs on transparency, so this is just filling the glyph mask with the target colour.
  • Backgrounds swap (17, 17, 38), which is the exact colour of images/bgs/000.png. A page whose background is 000.png is therefore a flat fill of z[7].

09 Fonts

The fonts are bitmap sprite sheets, not vector faces. Each lives at images/fonts/<name><size><style>.png, all lower-case — hypnofont0n.png, clownhand1b.png.

Every sheet is a grid eight columns wide, filled row-major with this character set:

ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz
0123456789.,;:?!-_~#"'&()[]|`\/@°+=*$£€<>

Size class 0 appends three more: % ■ ▲.

Size classCellSheet
07 × 756 × 84
114 × 12112 × 144
221 × 21168 × 252

Per-font metrics live in images/fonts/fontdata.ini, keyed by <Font><size><style>:

[HypnoFont0n]
spacing=0
lineheight=1
charwidths=.,li^2^|;:!'` [(^3^)]<>ITZjcnrtxt1^4^...

charwidths is a ^-separated alternating list of character set and pixel width. Characters not listed keep the cell width. spacing goes between characters and lineheight between lines — and lineheight is often negative.

Layout is Construct 2's Spritefont algorithm: word-wrap at the box width breaking on space, tab and hyphen, then measureWidth = Σ(charWidth + spacing) − spacing, then align inside the box using z[9].

10 Page music

Webpage z[4] names either a plain .ogg or a .hsm module, and the runtime branches on the extension. An .ogg goes straight to the audio plugin, with its title|artist read from a sibling .txt. Anything else is JSONLoaded as an array and sequenced.

KindPagesDistinct files

silent315—

A tracker module, also a c2array

.hsm overloads its axes exactly the way .hsp does:

AxisMeaning
xStep within the pattern, 1-based (PlayStep = CurrentStep + 1).
y5 × pattern + track, tracks numbered 1..5.
zPer-step parameter.

Row y = 0 and column x = 0 then do something else entirely:

  • x=0, y=0 — title and artist.
  • y=0, any x — the instrument table. Slot x holds a sample path, then loop period, stop, sustain and attack.
  • y=0, z=10 — doubling as the pattern sequence. Position x holds that slot's pattern index plus one; 0 is an empty slot.
  • x=0, y=5p+1 — pattern p's header: BPM, steps per pattern, beat division. It shares the row with track 1's pan and volume.

Steps

A step is a sixteenth note: secPerStep = 1 / (BPM / 60) / 4.

zMeaning
0Instrument slot. 0 means no note — this is the gate the runtime tests.
1Note. 100 is a rest.
2Pan, 0–100.
3Volume, 0–100.
4–16Per-step effects — echo, arpeggio, pitch shift, vibrato, filter. Each stored 0–100 and lerped into its own range.

Pitch is resampling, not MIDI

A 60-entry frequency table (FREQOUT, 11025 … 332995) is indexed by note % 100, and the playback rate is that value over 44100. Index 24 is exactly 44100, so note 24 plays the sample at its own pitch — and it is by far the most common note in the shipped modules.

Gain

Track and step gain run through two different log divisors, which as amplitudes are two different curves:

trackAmp = (masterVol/100 × trackVol/100) ^ 1.25   // log10(x)/0.04
stepAmp  = (stepVol/100) ^ 2.5                     // log10(x)/0.02

Pan is summed rather than averaged: track and step each map 0–100 onto −1…+1, and the two are added, so 50/50 is centre.

An envelope bug worth keeping

The instrument envelope converts each duration with ceil(lerp(0, 34, v/100)), after which 1 and 2 become 0.25 and 0.5 steps. The sustain branch then writes its result into the stop slot instead of its own. It is a real bug in the shipped game, and it rarely bites — 934 of 1003 instruments leave sustain at zero — but a renderer that quietly fixes it stops matching what players actually heard.

11 Known gaps

  • Word art. Stored as ordinary Gif elements pointing at a word-art directory. The per-letter composition happens in the Page Builder, not at page load, so a renderer sees only the finished directory.
  • Shaders. alphadither and AdjustHSL are pixel effects. A CSS renderer can approximate them with opacity and filter, but not match them exactly — the dither is a real ordered 4×4 pattern. Note that its parameter runs opposite to the name: 0 is fully transparent, 1 opaque.
  • State selection. Resolving anything other than DEFAULT needs live game save state.
  • Tracker effects. The .hsm per-step slots z[4]–z[16] are parsed but not rendered; they drive echo, arpeggio, pitch-shift, vibrato and filter timers.
